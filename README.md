# HAVAL M6 Setup

- Официальный лаунчер отключён
- Радио отключено
- Проблемы со временем исправлены

## Структура

- `windows/` — `platform-tools`, `apk`, bat-файлы
- `linux/` — `platform-tools`, `apk`, shell-скрипты

## Порядок установки (Windows)

1. Подключите ГУ к компьютеру кабелем с передачей данных.
2. Включите «Отладку по USB» на ГУ и подтвердите запрос на экране.
3. Откройте папку `windows`.
4. Запустите `УСТАНОВИТЬ.bat` и следуйте подсказкам в окне.
5. При необходимости используйте `ПРОВЕРКА.bat`, `ОТКАТ.bat`, `set-time.bat`.

## Порядок установки (Linux)

1. Подключите ГУ к компьютеру кабелем с передачей данных.
2. Включите «Отладку по USB» на ГУ и подтвердите запрос на экране.
3. Откройте папку `linux` в терминале.
4. Запустите `./УСТАНОВИТЬ.sh` и следуйте подсказкам.
5. При необходимости используйте `./ПРОВЕРКА.sh`, `./ОТКАТ.sh`, `./set-time.sh`.
